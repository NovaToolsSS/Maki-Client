# 🍣 Maki Client - Build Guide

## Schnelle Erstellung

### Windows:
```
build.bat
```
Oder doppelklick auf `build.bat`

### Mac/Linux:
```bash
bash build.sh
```

### Alle Systeme (Python):
```bash
python3 build.py
```

---

## Ergebnis:

✓ `Maki-Client.mcpack` wird erstellt  
✓ Fertig zum Download
✓ Direkt auf iPad installierbar

---

## Installation auf iPad:

1. Download: `Maki-Client.mcpack`
2. Öffnen (Minecraft startet automatisch)
3. "Addon importieren" tippen
4. Neue Welt mit Addon erstellen
5. Fertig! 🎮

---

## Verwendung im Spiel:

```
/function maki/on
```

ClickGUI mit 50 Cheats öffnet sich!
